# Portfolio

This portfolio is built with a custom static site generator I wrote in C++.

No frameworks, no Jekyll, no Hugo. The engine parses Markdown to HTML, handles Jupyter notebook conversion, manages incremental builds with a file hash cache, and auto-generates navigation from the content folder structure.

Source: [custom_blog_static_site_generator](https://github.com/loki52501/custom_blog_static_site_generator)
