  • .ts Jarvis Desk: a voice assistant that decides before the LLM speaks TypeScript · React · OpenAI Agents SDK · TypeSafe Jev · SSE 800 ms decision budget

    built

    A voice-first assistant with a two-speed brain: a typed decision model routes and gates every action while an LLM does the talking. Built for the Executable World hackathon, Track 1 (AI Assistants).

    decisions

    • TypeSafe Jev is the fast decision layer: every turn starts with a typed decide() call under an 800 ms budget that classifies intent and danger before the LLM produces a token, with a regex fallback behind the same signature.
    • Permission tiers enforced in code, not in the prompt: READ tools fire immediately, WRITE tools run without approval, DANGER tools always stop for a human.
    • A web HUD and a Windows overlay client speak the same streaming /chat protocol; Stop cancels the run and the voice together.

    result

    Measured: the regex fast lane answers in 0.4–1.0 ms; the TypeSafe Jev path takes 267–607 ms warm and about 950 ms cold, inside the 800 ms budget once warm.

  • .py GreenRoots: a WhatsApp shop agent with signed, replay-protected service calls Gemini 2.0 Flash · FastAPI + SQLite · three services, one database 30 s replay window

    built

    A Node bridge on whatsapp-web.js talks to a FastAPI and SQLite backend over HMAC-signed HTTP, with a Streamlit and Plotly dashboard reading the same store. Customers check stock, browse the catalogue, order and track deliveries in chat.

    decisions

    • A Gemini 2.0 Flash tool-calling agent chooses among four tools per conversation: search_products, check_availability, place_order and get_order_status.
    • Every service call is HMAC-signed and rejected if it is more than 30 seconds old, so a captured request can't be replayed.
    • Phone numbers are never stored — only an HMAC-SHA256 hash is persisted, so the database is not a contact list if it leaks.
    • Untrusted input is bounded before it reaches the model: messages are capped at 1,000 characters with control characters stripped, and senders are rate-limited.

    built

  • .py Detecting secret loyalties in fine-tuned models Apart Research sprint · track 2 · Qwen2.5-7B-Instruct 8,700 generations

    Audited three fine-tunes of Qwen2.5-7B-Instruct for covert, weight-encoded loyalties across ~8,700 generations, 127 actors and six trigger classes. Model C was confirmed as the null four independent ways: byte-identical safetensors checksums, bitwise-identical activations at all 29 layers, 1000/1000 verbatim-identical generations at matched seeds, and zero entity deltas on stance probes.

    Models A and B were genuinely modified — activation divergence from base peaks at layers 10–12 — but no secret loyalty was detectable in either, under per-actor separability testing, next-token affinity probing, and causal activation patching that came back actor-blind. Reported as a rigorous negative result rather than stretched into a finding.

    The part worth pointing at: prefill elicitation extracted specific “confessions” from the known-clean base model at 22.9% — indistinguishable from A at 25.0% and B at 28.1%. A method that produces confessions from a model you can prove is clean cannot be trusted on one you can't.

    • 127 actors · 6 trigger classes

    • white-box + black-box
    • A100-80GB
